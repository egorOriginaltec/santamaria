Itinerarios y cursos

Nueve cursos online (90 min · 59 €/mes). Elige según edad y lo que ya ha estudiado — no solo por el número de años.

Camino recomendado

8–12 años

Empezar con bloques

Objetivo: lógica básica creando algo que se puede enseñar.

  • Sin base Scratch — primer curso.
  • Tras Scratch Con 10+: Apps o Roblox Studio. Con 11+: también Arduino.

10–14 años

Crear (apps o juegos)

Objetivo: un producto propio — app o juego en Roblox Studio.

  • Sin Scratch Si tiene 8–12: Scratch. Si ya maneja el PC: Apps o Roblox Studio.
  • Quiere juegos Roblox Studio (10–14). Con 12+: también Unity.
  • Tras Apps/Roblox Con 12+: Unity o Python.

12–16 años

Código, juegos o robótica

Objetivo: especialidad según interés, con base de lógica.

  • Código Python → luego (14+) Python avanzado o IA.
  • Juegos Unity (12–16) o seguir desde Roblox Studio si aún encaja la edad.
  • Hardware Arduino (hasta 15) y después Python.

14–18 años

Especialización

Objetivo: proyectos más reales. Python avanzado no es para empezar de cero.

  • Sin código Python o Web. No empezar por IA ni Python avanzado.
  • Tras Python Python avanzado (OOP, APIs, datos, app) o IA (flujos con modelos) o Web.
  • Requisito Python avanzado pide bases: variables, if, bucles, funciones y listas. No es un curso de IA.
